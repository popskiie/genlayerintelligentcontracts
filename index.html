Core Concepts
🧠

Intelligent Contracts

Smart contracts that can read natural language, access real-time web data, and make decisions about subjective outcomes without needing centralized oracles.

⚖️

Optimistic Democracy

Multiple AI validator nodes independently run the same contract. Their results are compared and consensus is reached via a staking-weighted vote.

🔗

GenVM

A Python-based execution environment that lets developers write Intelligent Contracts using familiar syntax with built-in LLM and web-access primitives.

# GenLayer Intelligent Contract
from genlayer import gl, contract

@contract
class DisputeResolver:

  def evaluate_claim(self, claim: str) -> dict:
    """AI-powered claim evaluator.
    Validators independently assess
    the claim and reach consensus."""

    result = gl.exec_prompt(f"""
      Evaluate this claim objectively:
      '{claim}'

      Return JSON:
      {{
        "valid": true/false,
        "confidence": 0.0-1.0,
        "reasoning": "explanation",
        "verdict": "APPROVED/REJECTED"
      }}
    """)

    return gl.json(result)

  def resolve_dispute(self, party_a, party_b):
    evidence = gl.get_webpage(party_a.evidence_url)
    return self.evaluate_claim(evidence)

01

Write an Intelligent Contract

Developers write contracts in Python using the GenLayer SDK. Unlike traditional smart contracts, these can call gl.exec_prompt() to invoke LLMs and gl.get_webpage() to read live data.

from genlayer import gl, contract

@contract
class MyContract:
  def check(self, claim: str):
    return gl.exec_prompt(f"Is this true? {claim}")
02

5 Validators Run Independently

When a contract is invoked, 5 randomly selected validator nodes each execute the contract with their own LLM. Non-deterministic calls like exec_prompt() may produce different outputs per validator.

03

Optimistic Democracy Reaches Consensus

The Leader validator proposes a result. The other validators accept or reject it. If ≥ 2/3 agree, the result is finalized on-chain. If there's dissent, an appeal round begins with more validators.

04

Result is Written On-Chain

The consensus outcome is committed to the GenLayer blockchain — transparent, immutable, and verifiable by anyone. No single entity controls the result.
